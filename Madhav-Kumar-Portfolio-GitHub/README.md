Welcome to the official source code for **Madhav Kumar's** executive portfolio website. 

Designed for both **mobile smartphones** and **Windows desktop/laptops**, this high-performance website features:
- **Personal Brand Logo**: Madhav's portrait embedded into the navigation brand logo, hero card, and website favicon.
- **AI Executive Showcase**: Highlights AI strategy, automation workflows, and technological leadership at **Micromaster India Pvt Ltd**.
- **Online Social Development Focus**: Highlights digital community building, audience reach strategies, and content synergy.
- **Modern Interactive UI**: Dark & Light theme switcher, ambient glow effects, responsive navigation drawer, and 1-click email copy.
- **1-Click vCard Contact Saver**: Visitors can tap or click to save Madhav's contact information directly to their smartphone (iOS / Android) or PC address book.

## 🚀 How to Publish on GitHub Pages (Free Live Website)

You can launch this website live on the internet with a free GitHub link (`https://<your-username>.github.io/<repository-name>/`) in 3 simple steps:

### Step 1: Create a New GitHub Repository
1. Log into your [GitHub account](https://github.com).
2. Click the **+** (plus icon) in the top right and select **New repository**.
3. Name it: `madhav-kumar-portfolio` (or your preferred name).
4. Set it to **Public**.
5. Click **Create repository**.

### Step 2: Upload Files
- **Option A (Web Upload - Easiest)**:
  1. On the new repository page, click **uploading an existing file**.
  2. Drag and drop all files and the `assets/` folder from this folder into GitHub.
  3. Click **Commit changes**.
- **Option B (GitHub Desktop)**:
  1. Open GitHub Desktop.
  2. Select **Add Local Repository** -> choose this folder.
  3. Publish repository to GitHub.

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (tab at the top).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment** > **Branch**:
   - Select **main** (or **master**).
   - Select folder: **/ (root)**.
   - Click **Save**.
5. Wait ~30 seconds and refresh the page. GitHub will give you your live URL:
   `https://<your-username>.github.io/madhav-kumar-portfolio/`
